340B Navigator on Microsoft Agent Framework

A private 22-lesson course on the Microsoft Agent Framework in C# and .NET 10, one framework feature per lesson, building a policy navigator for the 340B Drug Pricing Program as its capstone. A compliance engine computes every verdict and the model only picks the tools and explains the result, and risky actions wait for a person's approval. The capstone runs on Azure Functions; a merge that changes it redeploys it and runs a smoke test with the real model. All data is synthetic. One of a series of agent-framework courses built on the same skeleton so the frameworks can be compared like for like.

A private 22-lesson course on Google's Agent Development Kit 2.x in Python, built around StandBy MC, a backstage co-host adapted from the StandBy event console that helps a live-event MC with the run of show, DJ cues and team scores, by text or by voice. It works a sample wedding reception with invented people. The service runs privately on Cloud Run behind a sign-in, redeployed with a live smoke test whenever a merge changes it. Part of the same agent-framework series.

WebAI 2026 Badge

Patched firmware for the WebAI 2026 conference's ePaper badge (an Espruino ESP32-C3 board). The badge front carries a LinkedIn QR code on a clean layout, and the agenda pages are replaced with GitHub profile pages: a contribution heatmap, the language mix, a GitHub QR code and 20 repositories, with the LEDs as a redraw progress bar.
