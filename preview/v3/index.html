340B Navigator on Microsoft Agent Framework

A private 22-lesson course on the Microsoft Agent Framework in C# and .NET 10, one framework feature per lesson, building a policy navigator for the 340B Drug Pricing Program as its capstone. A compliance engine computes every verdict and the model only picks the tools and explains the result, and risky actions wait for a person's approval. One of a series of agent-framework courses built on the same skeleton so the frameworks can be compared like for like.

Guest Experience App

An invite-only app for the guests and hosts of a multi-day event, built first for an Indian wedding. Guests get painted schedule cards and the ceremony program, live announcements with push, chat, travel and arrival tracking, find-my-seat, a disposable-camera film roll with a shared gallery, and trivia, photo challenges, predictions and leaderboards, in one of four watercolour themes. Hosts run the event from the same app: they post announcements and edit the schedule, add, edit and settle challenges, import the guest list from a CSV and share the invite codes, arrange the seating chart, set up film rolls and chat channels, and hide photos from the gallery. Flutter on Android and the web (iPhone guests install the web app), over a Go API on Cloud Run with Firestore, Cloud Storage and Firebase push. Open gaps: it has only run on a sample wedding with invented guests and has not been used at a real event; there is no App Store build yet; push has been tested with stand-ins, not confirmed on real phones; and it has not been tried with more than a few dozen guests.
